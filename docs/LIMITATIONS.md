# Limitations

Initial results will be exploratory because the first experiment uses a small number of tasks, models, and repetitions.

Potential limitations include:
- Small task set and limited language coverage.
- Model/provider version changes.
- Nondeterminism in concurrency and timing tests.
- Differences in model tool-calling behavior.
- Subjectivity in diagnosis and patch-quality scoring.
- API/provider failures and cost variability.
- Task construction bias and benchmark contamination.

Reports must disclose these limitations and avoid universal claims or unsupported rankings.
